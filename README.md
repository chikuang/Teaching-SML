# Topics of Statistical Learning

**Topic Course · Chi-Kuang Yeh**

- Course: https://chikuang.github.io/teaching/statistical-learning/
- Book: https://chikuang.github.io/teaching/statistical-learning/Topics-of-Statistical-Learning.pdf
- Canonical source: [chikuang/Teaching-SML](https://github.com/chikuang/Teaching-SML), branch `main`
- Published output: `chikuang/chikuang.github.io`, `teaching/statistical-learning/`

Fourteen developed chapters cover weak supervision, PU and UU learning, pairwise and contextual preferences, online convex optimisation, bandits, duelling bandits, selective inference, hierarchical clustering, k-means, and research synthesis. Every chapter has derivations, worked examples, a standalone experiment with executed output, exercises, and separately revealable solutions. The course guide preserves a proposed 15-week graduate teaching route, while the book supports independent study.

Three browser demonstrations provide incomplete-label risk estimation, UCB exploration, and an exact elementary Gaussian selection example. The elementary example is not a cluster-significance calculator.

## Build

Use Python 3.12 or later and R 4.3 or later. Core chapter labs use base R. The two clustering chapters additionally run the authors' selective-inference procedures when `clusterpval` and `KmeansInference` are installed; the recorded output states their status. Read the relevant chapter and authors' documentation before installing specialist packages.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/build.py --format html
```

The build executes all 14 R scripts in fresh processes and temporary working directories, embeds stdout and generated figures, records hashes and the R version, packages downloads, and runs Sphinx with warnings treated as errors. Set `RSCRIPT` if the R executable is not on PATH.

To build the complete PDF from the same chapter tree, install XeLaTeX, latexmk, and the DejaVu font family, then run:

```bash
python scripts/build.py
```

Use `--skip-labs` only for an editorial rebuild that intentionally reuses already executed outputs. It fails if no execution manifest exists. Changed R code must be executed again before publication.

```bash
python scripts/check_site.py
node scripts/check_demos.cjs
python -m http.server 8768 --directory _build/html
```

The last command is for ordinary local use. Managed preview environments may provide their own preview supervisor.

## Authoring

- `docs/chapters/*.md`: canonical MyST lessons.
- `labs/*.R`: complete deterministic worked experiments.
- `docs/_generated/`: output includes generated by actual R runs.
- `docs/_static/lab-outputs/`: recorded results and execution manifest.
- `docs/_static/course-demos.js`: local browser simulations; no external data or API calls.
- `docs/conf.py`: book navigation settings and PDF configuration.
- `docs/index.md`: chapter tree and homepage.

Keep the distinction between required base-R calculations and optional author-package calculations explicit. Do not publish estimated-scale, altered-algorithm, or post hoc multiple-comparison results as exact selective inference without a supporting method. Keep lecture exercises and worked solutions separate in the source.

## Publish without replacing other courses

Build and validate first. Copy only the contents of `_build/html/` into the deployment repository's `teaching/statistical-learning/`. Commit the canonical source and generated course output. The personal website's Topic Course listing is maintained in `config.toml` at the root of `chikuang/website`.

Preserve existing website files, other teaching directories, and CVs. Never use `hugo --cleanDestinationDir` on the public website checkout. A full Hugo regeneration is not needed to build this course.
